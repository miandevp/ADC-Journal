# Resumen 

### Motivación:
Los procesadores constituyen la base de los sistemas computacionales modernos y permiten la ejecución de programas de propósito general.

### Problema:
Es necesario comprender el funcionamiento interno y el diseño de los procesadores para analizar y desarrollar nuevas arquitecturas.

### Contenido:
Se estudiará la microarquitectura monociclo (*single-cycle*) de RISC-V.

### Conclusión:
La implementación de un procesador RISC-V monociclo permite comprender los principios fundamentales de ejecución de instrucciones y sirve como base para extender el soporte de la ISA completa.
